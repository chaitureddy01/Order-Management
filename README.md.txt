# Order Management System

## Overview

A Spring Boot REST API for managing products and customer orders.

## Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Features

- Add Product
- View Products
- Update Product
- Delete Product
- Create Order
- View Orders
- Automatic Stock Management

## REST APIs

### Product APIs

- POST /products
- GET /products
- GET /products/{id}
- PUT /products/{id}
- DELETE /products/{id}

### Order APIs

- POST /orders
- GET /orders
- GET /orders/{id}

## Tools

- Eclipse
- Postman
- MySQL
